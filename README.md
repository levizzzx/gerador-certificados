# Gerador de Certificados - Lira Safety

Ferramenta para automação e geração em lote de certificados nos modelos oficiais da [Lira Safety](https://lirasafety.com.br/).

**App:** [geradorlirasafety.streamlit.app](https://geradorlirasafety.streamlit.app/)

## Como usar
1. Envie a lista de alunos (`.docx`, `.xlsx` ou `.csv`).
2. Envie o modelo do certificado (`.pptx`).
3. Baixe os certificados gerados.
